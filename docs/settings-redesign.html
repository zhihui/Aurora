配置目录：~/.aurora · 删除 agent 只移除配置，不动目录。右键任意行可打开操作菜单。
  • 分隔线缩进 62px（14 padding + 36 头像 + 12 间距），与名称文字左缘对齐——缩进表达层级（layout.md）。
  • 「N 个技能」从胶囊降为纯文字 12pt muted：它是次要信息，胶囊的底色块在每行重复是噪音（设计原则 › Simplicity）。
  • ⋯ 按钮常驻但低对比（默认 55% 透明、行 hover 加深、自身 hover 加底色，与技能卡片 × 同一约定）；整行右键弹出同一菜单（macOS 用户期望右键菜单，MyGo 有 ContextMenu API）。
  • 行不再是按钮、不导航、无 chevron：去 Agent 技能页改由该页顶部的 agent 胶囊负责（此前已改为全量平铺）。
  • 路径行去掉文件夹图标、字号 12→11 mono（macOS 最小 10pt，typography.md），行高 64→54，列表更紧凑。
  • 配置目录挪到列表下方 footer（分组列表的 footer 惯例），头区只剩一行说明。
