Aurora UI 组件参考

本页盘点 Aurora（Go + MyGo ui 包，native 渲染，无 HTML）用到的全部 UI 组件， 记录每个组件的规格、状态与所在源码位置，并标注对应的 Apple HIG 章节（apple-design 技能的 references/hig/）。用途：后续优化 UI 时的现状基线与对照表。文末「改进机会」 给出了逐项对照 HIG 后确有更好替代的建议与评估后保留现状的清单。 视觉 mock 为 HTML 近似，精确行为以源码为准；所有尺寸单位为 DIP。

设计 Token（颜色）

来自 MyGo 默认主题 ui/theme.go（LightTheme / DarkTheme）。UI.md 设计原则 4：一律用主题色，不写字面量；浅色变体用 t.Accent.Alpha(0.12) 这类透明度派生。alpha 派生是本项目视觉语言的核心（选中底、焦点环、徽章底全部是 accent 的 alpha 变体）。

组件评估结论
侧栏彩色方块图标sidebars.md（2026-06 更新）默认希望侧栏图标跟随系统 accent 色，但允许"sparingly"使用固定色表达含义。Aurora 四枚彩色 tile 是有意的品牌识别（参照 branding.md 在熟悉的尺寸/位置上做再样式化）。保留；若哪天想更"原生"，退路是单色 accent 符号，属于口味而非对错。
设置放在侧栏页（非独立设置窗口）settings.md › Desktop (macOS) 的独立设置窗口 + 工具栏 pane 是给「通用、低频」选项的；Aurora 的「设置」实际是 agent 管理（添加/打开目录/删除），属于任务性内容，settings.md › Task-specific options 恰恰要求这类选项"in the screens they affect"。保留；若以后出现真正的通用偏好（外观、更新等），再开独立 Settings 窗口并配 ⌘,。
搜索框在顶栏右侧（trailing）正是 search-fields.md › Tablet and desktop 推荐的工具栏 trailing 位置；输入即过滤（"start search immediately"）也符合。完全合规。
顶栏布局（标题左、操作右、唯一主按钮）符合 toolbars.md › Item groupings（trailing 放重要操作与搜索）和 buttons.md（每视图一个 prominent）。合规。
卡片网格展示技能collections.md 提示纯文本信息优先考虑表格/列表，但 Aurora 卡片承载每张卡独立的 agent 胶囊开关（逐项交互），网格的等高等宽让胶囊行对齐易扫——collection 用在这里有正当理由。保留；若技能数涨到数百，再考虑列表视图。
胶囊家族（开关/选择器/成员/添加）toggles.md 认可"buttons that behave like toggles"（用背景变化表达状态）；胶囊 24px 高满足桌面最小 20×20，且语义区分（开关两态描边/选择器实心填充/成员不可点）清晰。保留，仅按上面第 3 条补对勾。
Modal 三段式 + AlertDialog 确认删除符合 modality.md（单一短任务、明确出口）与 feedback.md（不可逆操作才警告；删除技能包/技能是不可逆，包内移除可重做故不确认——分寸正确）。合规。
无边框卡片 + tag 表达来源符合 layout.md › Visual hierarchy（用容器形状分组）与 branding.md（品牌色克制，蓝色只出现在主操作和选中态）。合规。

优化前检查清单

改动任何组件前对照（来自 UI.md 设计原则与 apple-design 技能的审查框架）：

  • 状态完整性（UI.md 原则 2）：默认 / hover / 选中 / 焦点 / 禁用全部有定义；状态切换不引起布局抖动（边框恒宽、Absolute 定位的显隐控件）。
  • 主题色（UI.md 原则 4）：不写字面量，浅色变体用 Alpha 派生；深浅两套外观都验证。
  • 一致性：三个卡片页内容区规范一致（改一处改全部）；弹窗统一三段式结构；页面顶栏一律 paneHeader。
  • 无障碍（Lens 1）：icon-only 控件带 .Label()；字号不低于 10pt；点击区桌面最小 20×20（现状已达标）；语义不靠颜色单独传达（色都配了文字，开关胶囊另有对勾）。
  • 验证：视觉变更先临时 render_*_test.go 截图两种状态自查，再三件套 gofmt -w . && CGO_ENABLED=0 go test ./... && go tool mygo vet .，删临时文件。
  • 同步文档：改动涉及 UI.md 描述的规范时，同一改动里更新 UI.md；组件规格变化时更新本页。
